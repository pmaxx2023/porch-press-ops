## How to play

1. Read the cold open in order: **D001 → D002 → D003 → D004**.
2. Follow the first research ask: verify both marriages using the **research catalog** cues (dates/places already on the opening paper).
3. Work in short loops: observe → hypothesis → pull record → compare → revise.
4. Use the worksheets. Cite exhibit codes.
5. Answer final adjudication questions **A–D**.
6. If stuck, open **one** hint rung. If still stuck after H8, commit your best answer, then open the sealed packet.
